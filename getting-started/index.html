01 / INSTALL

Add grape-oas

Use Ruby 3.2 or newer and Grape 3.0 or newer. Add the gem to your application’s Gemfile:

gem "grape-oas"

Then install your dependencies:

bundle install

02 / DEFINE YOUR API

A small, working example

This API documents an integer path parameter and exposes a specification at /swagger_doc.

# frozen_string_literal: true

require "grape_oas"

class CatalogAPI < Grape::API
  format :json

  desc "Find a book"
  params do
    requires :id, type: Integer, desc: "Book ID"
  end
  get "books/:id" do
    { id: params[:id], title: "The Ruby Programming Language" }
  end

  add_oas_documentation(
    info: { title: "Catalog API", version: "1.0.0" },
  )
end

Mount CatalogAPI in your Rack application as you would any Grape API.

03 / SERVE THE DOCUMENT

Choose your OpenAPI format

add_oas_documentation serves JSON and excludes documentation routes from the specification by default.

EndpointFormat
/swagger_docOpenAPI 3.0, the default
/swagger_doc?oas=2OpenAPI 2.0
/swagger_doc?oas=3.1OpenAPI 3.1

04 / GENERATE DIRECTLY

Export without an endpoint

With your API loaded, generate a Ruby hash and serialize it to JSON:

require "json"

spec = GrapeOAS.generate(app: CatalogAPI, schema_type: :oas31)
File.write("openapi.json", JSON.pretty_generate(spec))

Use :oas2, :oas3, or :oas31 to choose the format. Explore more usage examples ↗

05 / ADD INTEGRATIONS

Bring your schemas along

Install the integrations your application uses. They are optional dependencies:

gem "grape-entity"    # Response entities
gem "dry-validation"  # Validation contracts
gem "dry-schema"      # Standalone schemas
