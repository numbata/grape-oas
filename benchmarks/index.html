REPRODUCIBILITY

What we measured

One warmup generation per case, followed by 10 measured calls to GrapeOAS.generate. Timing uses Ruby’s monotonic clock. API construction and JSON serialization happen outside the timed operation. Garbage collection stays enabled.

Each version runs in a separate process with the same Ruby and locked dependencies. Format order is 2.0, 3.0, then 3.1. The API defines an integer path parameter and an optional string query parameter on each route. These results do not measure entity or contract introspection, HTTP throughput, or first-generation startup cost.
